DevPanel 0.7.0 gives repository cards a quieter look, sets each name in its own display font, and opens a repository's web page in one click.

- **Quieter cards:** suggested fixes such as Commit, Pull and Stash moved off the cards and list rows into the details panel, and the coloured stripe on a card's edge is gone. The status chip shows the state.
- **Web page:** a globe button on each card, under Open in, and in the ⋯ menu opens the repository on GitHub, GitLab, Bitbucket, Codeberg, Gitea, Forgejo, sourcehut or Azure DevOps. When the address DevPanel derives is wrong, set your own in Edit… → Web page.
- **Name fonts:** the letter badge is replaced by the repository's name in one of 13 bundled pixel, cyber, tech and chip fonts, picked per repository. Edit… → Name font changes the font, weight and italic. Settings → New repositories can start new ones in the plain font instead.
- **Density:** Settings → Density makes the window Compact, Comfortable or Spacious.
- **Bigger window:** DevPanel now opens at 1440 × 960.
