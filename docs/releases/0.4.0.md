DevPanel 0.4.0 makes [Commits](https://github.com/an-dr/commits) its git client.

## Commits comes with DevPanel

- Every release now carries Commits 1.9.1. Installing DevPanel installs Commits too when it is not installed yet; an existing Commits is left alone, since it updates itself. Each download is about 25 MB larger.
- **Open in Commits** sits beside every card's Open button and in the drawer. A problem opens in the Commits view that fixes it: conflicts and unfinished operations on the conflict view, uncommitted work on the changes, a branch out of step selected in the graph. Commits opens in DevPanel's light or dark mode and colours, and reuses its window.
- DevPanel's repositories appear in Commits' repository selector, and both apps show the same problems in the same words.

## DevPanel

- One window: launching DevPanel again brings the running window to the front. `devpanel <folder>` adds that repository, or every repository under the folder, and opens it.
- Installing adds DevPanel to the Start menu or application menu and puts **Open in DevPanel** on folders. Settings → Desktop removes or restores it.
- Updates: Settings shows **Update to X** when a newer release exists, and installs it only when you click. Starting with this release, releases publish what that check reads.
- A commit or checkout made outside DevPanel shows up within a second, without switching windows.
- A new icon set, sharp at every size from 16 to 512 px.
- Built on bones 2.0.0.

## Downloads

One zip per platform: Linux x64, Windows x64, Windows ARM64. Unzip and run `devpanel/devpanel`, or install with `devpanel/0.4.0/devpanel-app --install`. The `-update.zip` files and `devpanel-<platform>.json` manifests are for the in-app updater.
