DevPanel 0.8.0 opens VS Code on Windows again, offers more editors, agents and apps, hides the ones you do not have, and can keep repositories pulled in the background.

- **VS Code on Windows:** "Open in VS Code" failed with "not a valid Win32 application". DevPanel now starts `code.cmd` instead of the shell script VS Code ships beside it (bones 3.0.1).
- **More tools:** Cursor, Windsurf, Zed, Codex CLI, and the Claude and ChatGPT desktop apps join the defaults. An existing setup gets them once; a default you remove stays removed.
- **Only usable tools:** a tool that is not installed is hidden from cards, menus and the details panel, and Settings → Tools marks it "not installed". DevPanel checks again when its window regains focus.
- **Turn tools off:** each tool in Settings → Tools has an On checkbox.
- **App tools:** a new App kind opens a desktop app that takes no folder, by its Windows AppUserModelID or macOS application name.
- **Pull automatically:** Settings → Pull automatically fast-forwards every repository not pulled for 1, 4, 12 or 24 hours, or a week. A repository with local commits, conflicts or a merge in progress is left alone.
