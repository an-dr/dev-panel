DevPanel 0.5.0 installs itself from its own Settings and ships one zip per platform.

- **New:** Settings → Installation has an **Install** button whenever DevPanel runs from somewhere other than its install, such as an unzipped download. It does what `devpanel-app --install` does: installs DevPanel to `~/.devpanel/app`, installs Commits when it is missing, and adds DevPanel to the application menu or Start menu.
- **Changed:** Register and Unregister appear only once DevPanel is installed, since the menu entry always starts the installed copy.
- **Changed:** each platform's zip is now a single version folder, with `devpanel-app`, its launcher and the bundled Commits. Unzip it, run `devpanel-app`, and click **Install**. The same zip is the update payload, so releases no longer carry a separate `-update.zip`.

From 0.4.0 on, Settings offers this update when it starts.
