DevPanel 0.4.1 fixes starting on Wayland desktops.

- **Fixed:** DevPanel 0.4.0 failed to start on Wayland sessions that set `GDK_BACKEND`, such as COSMIC, with "failed to init GTK, web panels require X11/Xwayland". DevPanel again sets `GDK_BACKEND=x11` for itself, and programs it opens get your own value back. A terminal it opens runs under Xwayland.

Everything else is as in [0.4.0](https://github.com/an-dr/dev-panel/releases/tag/v0.4.0). From 0.4.0 on, Settings offers this update when it starts.
