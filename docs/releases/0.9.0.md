DevPanel 0.9.0 runs your repositories' just recipes from a larger details window, signs in to GitHub to browse and clone your repositories, and edits your global Git settings. It removes the Install window and Run command.

- **Just recipes:** a repository with a [justfile](https://github.com/casey/just) gets a `just` tag on its card and a Recipes section in its details: every public recipe on one line, with inputs for its parameters. Run shows that recipe's output right under it, in a box you can enlarge or close. Hide moves rarely used recipes into a collapsed Other group; the choice is saved with the repository and travels with an exported list. `just` must be installed and on `PATH`.
- **Details window:** clicking a card opens its details in a window over most of the page, actions on the left and status, recipes, changes and recent activity on the right. Esc, the close button or a click outside closes it.
- **Accounts:** sign in through GitHub CLI in your browser, then filter and clone the repositories you can access. Install `gh` first; DevPanel does not store its credentials.
- **Git configuration:** edit common global Git settings, such as your commit identity, default branch, pull and push behaviour, editor, line endings and commit signing.
- **Cleaner output:** job output no longer shows terminal colour codes from pwsh, cargo or just.
- **Removed:** the Install window, Run command and the saved per-repository install command. Add an `install` recipe to the repository's justfile instead. Existing settings files still load; the old command is ignored.
