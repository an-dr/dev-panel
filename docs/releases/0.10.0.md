DevPanel 0.10.0 shows and updates a repository's submodules, nested ones included, opens on your repositories, and gathers its settings into tabs.

- **Submodules:** a repository with submodules gets a button on its card that lists them, nested ones indented under their parent, each with its state against the commit its parent records: at recorded, pointer moved, modified, not cloned, or conflict. A submodule opens in the same details window as a repository, marked with the path of its parents; Clone or Reset puts it back at the recorded commit, and Update all does so for every submodule. Add to DevPanel tracks one as a repository of its own. A submodule on a detached HEAD, the usual way it sits at its recorded commit, counts as clean.
- **Repositories first:** DevPanel opens on Repositories. Overview is now Needs attention, under Favorites in the sidebar, with the totals and the repositories that need a fix. A start page or sidebar order you saved keeps working.
- **Cards:** every card has the same size, and two columns fit in narrower windows; a long name keeps its place and the group and just tags wrap below it.
- **Settings tabs:** Settings has General, Tools and Git tabs. Tools holds the tool list and the default tool, and Git the global Git configuration, which leaves the sidebar.
