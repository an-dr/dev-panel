DevPanel 0.5.1 makes the window smoother while DevPanel is working.

- **Fixed:** the page rebuilt itself for every message from DevPanel's host, up to 60 times a second while a fetch, pull or install printed output, and on every refresh even when nothing had changed. It now skips statuses that did not change, rebuilds at most every 50 ms, and redraws job output at most four times a second.
- **Fixed:** repository cards replayed their entrance animation on every rebuild, which looked like flicker. They now animate only when a view opens.

Everything else is as in [0.5.0](https://github.com/an-dr/dev-panel/releases/tag/v0.5.0). Settings offers this update when it starts.
