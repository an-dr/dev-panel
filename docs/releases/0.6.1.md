DevPanel 0.6.1 shows its own name and icon in Linux taskbars.

- **Fixed:** taskbars and docs such as COSMIC's showed DevPanel as "devpanel-app" with a generic icon. The window now matches the DevPanel menu entry that installing registers. If it still shows a generic icon, use Settings → Desktop → Register with system.
- **Fixed:** on Linux, dragging a repository onto Favorites or a group, or reordering the sidebar, started but never landed. Dragging now works there, a chip with the repository's name follows the pointer, the place it would land lights up, and sidebar items slide out of the way while you reorder them. Escape cancels a drag.
